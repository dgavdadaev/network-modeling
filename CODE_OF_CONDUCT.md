# Правила взаимодействия

Этот репозиторий предназначен для учебной работы и технического обмена знаниями.

При обсуждении изменений соблюдайте уважительный тон, обсуждайте код и результаты по существу, ссылайтесь на воспроизводимые факты и не публикуйте чужие персональные данные без согласия.

Недопустимы оскорбления, дискриминация, угрозы, спам и заведомо ложные результаты экспериментов.

Вопросы по содержанию материалов можно создавать в разделе **Issues** репозитория (если он включён). Для сообщений о возможных уязвимостях следуйте [SECURITY.md](SECURITY.md) и не публикуйте конфиденциальные сведения в открытых обсуждениях.
