# История изменений — лабораторная работа № 4

Документ отражает изменения проекта `labs/lab04/project`. Версии оформляются по принципам [Semantic Versioning](https://semver.org/lang/ru/). Тег и релиз будут созданы отдельно после окончательной проверки материалов.

## [Unreleased]

### Добавлено

- Python-скрипты для пяти воспроизводимых экспериментов в Mininet: `simple-delay`, `change-delay`, `jitter-delay`, `correlation-delay`, `distribution-delay`.
- Конфигурации Linux NETEM для постоянной задержки, её изменения, джиттера, корреляции 25% и нормального распределения.
- Скрипты Gnuplot и PNG-графики RTT для каждого сценария; сравнительный график в `change-delay`.
- Автоматизация запуска измерений, построения графиков и расчёта статистики через Makefile.
- Скрипты расчёта минимума, среднего, максимума и стандартного отклонения RTT.
- Сохранённые результаты ICMP-измерений в `.dat` файлах.
- Документация экспериментов и инструкции по воспроизведению в `README.md`.

### Изменено

- Проектная папка `labs/lab04/project` очищена от старых шаблонных Julia-файлов, не относящихся к экспериментам по NETEM.

### Проверено

- Успешное выполнение `make` и построение графиков для всех пяти сценариев.
- Повторный запуск `simple-delay` после очистки результатов.
- Сохранность исходников, результатов и графиков в пяти каталогах перед переносом из виртуальной машины.

## Планируемый релиз

Для публикации ЛР-4 предполагается отдельный тег **`lab04-v1.0.0`** на GitHub и GitVerse после создания и проверки отчёта, презентации и сопроводительных материалов. До фактической публикации этот тег не считается существующим.
