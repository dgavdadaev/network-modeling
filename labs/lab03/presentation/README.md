# Презентация ЛР-3: исходный Markdown и производные форматы

Главный исходник — `Lab03_Presentation_Source.md`. Каждый блок между `---` соответствует одному слайду. Содержимое текстовых слайдов, заголовки, подписи, пути к изображениям и заметки выступающего находятся непосредственно в Markdown.

## Состав

- `Lab03_Presentation_Source.md` — **исходник** презентации, 42 слайда.
- `image/1.png` — `image/29.png` — все 29 скриншотов практической части.
- `build_from_markdown.js` — генератор редактируемого PowerPoint из Markdown.
- `Lab03_Presentation_Cambria_Calibri.pptx` — готовый PowerPoint.
- `Lab03_Presentation_Cambria_Calibri.pdf` — экспорт этой же презентации в PDF.

## Оформление

- Шрифт заголовков: **Calibri (Headings)**.
- Шрифт основного текста, подписей и нижних колонтитулов: **Cambria (Body)**.
- Белый фон, тёмно-зелёный верхний колонтитул, золотистая линия, скриншоты и подписи — как в предоставленном образце.
- Удалены бывшие слайды **№4** («Практическая значимость») и **№44** («Материалы лабораторной работы»). Всего осталось **42**.
- Разделители не имеют нумерации, на остальных слайдах номер `1/34` – `34/34`.

## Повторная сборка из Markdown

Установите Node.js, затем в этой папке выполните:

```bash
npm install
npm run build
```

Скрипт читает **Markdown**, а не готовый PPTX, и создаёт заново `Lab03_Presentation_Cambria_Calibri.pptx`. Для корректного отображения в Microsoft PowerPoint желательно наличие Cambria и Calibri.

Экспорт в PDF: откройте PPTX в PowerPoint и используйте «Файл → Экспорт → PDF». При наличии LibreOffice возможен автоматический экспорт:

```bash
libreoffice --headless --convert-to pdf Lab03_Presentation_Cambria_Calibri.pptx
```

PDF, приложенный в архиве, уже экспортирован из PowerPoint-совместимого PPTX. При просмотре в Linux Cambria/Calibri могут заменяться совместимыми шрифтами, однако в самом PPTX указаны **Cambria** и **Calibri**.
