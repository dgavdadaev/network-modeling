
# Changelog

История изменений проекта лабораторной работы №3
по дисциплине «Моделирование сетей передачи данных».

Формат основан на Keep a Changelog.
Для релизов используется семантическое версионирование.

## [3.0.0] - 2026-10-10

### Added

- Создана базовая топология Mininet с двумя хостами
  h1, h2 и коммутатором s3.
- Реализован вывод IP- и MAC-адресов хостов.
- Добавлена топология с ограничениями CPU,
  пропускной способности, задержки и потерь.
- Разработан Python-скрипт автоматического
  эксперимента iPerf3.
- Добавлен Makefile для запуска и очистки результатов.
- Реализован экспорт результатов в JSON.
- Созданы семь PDF-графиков по результатам измерений.
- Добавлена инструкция по воспроизведению
  эксперимента в README.md.

### Changed

- Настроены окончания строк LF для файлов проекта.
- Интерактивный запуск Mininet заменён автоматическим
  выполнением эксперимента в lab_iperf3.py.

### Verified

- Проверена связность хостов в базовой топологии.
- Проверены ограничения сети с помощью tc.
- Подтверждены потери пакетов в ограниченной топологии.
- Проверена корректность JSON-файла.
- Успешно выполнены команды make clean и make.

### Results

- Первый эксперимент: 9,97 Мбит/с.
- Повторный эксперимент: 35,62 Мбит/с.
- Процедура эксперимента воспроизводится автоматически.
- Численные показатели отличаются между запусками.
