# Политика безопасности

Репозиторий содержит учебные примеры и результаты сетевых экспериментов. Они не предназначены для применения в промышленной инфраструктуре без отдельной проверки безопасности.

## Что нельзя публиковать

- Пароли, токены и приватные SSH-ключи.
- Конфигурации реальных сетей с закрытыми адресами и другими чувствительными деталями без разрешения владельца.
- Секреты в исходном коде, логах, JSON, скриншотах и записях экрана.

## Сообщение о проблеме

Если проблема связана с уязвимостью или раскрытием секрета, **не публикуйте её детали в открытом Issue**. Используйте приватный механизм сообщения об уязвимостях GitHub, если он включён для репозитория; иначе свяжитесь с владельцем репозитория через доступный непубличный канал.

Для обычных технических ошибок без конфиденциальных данных можно использовать Issues (если они включены).

Учебные материалы предоставляются без гарантий применимости к защищённым производственным сетям.
